# 🌙 JedaLayar

Aplikasi web edukatif berbahasa Indonesia untuk pelajar SMP/SMA tentang **kecanduan doomscrolling dan gangguan tidur** (topik Dampak Sosial Informatika).

## Fitur

- **Beranda & Ringkasan Masalah**: penyebab, dampak, dan pihak terdampak (pelajar, guru mapel pagi, orang tua).
- **Kalkulator Tidur & Batas Layar**: jam ideal mulai tidur dan jam menaruh gawai dari jam bangun, target durasi, dan jeda tanpa layar.
- **Simulator Hilangnya Jam Tidur**: tidur yang hilang per malam dan per minggu, tingkat risiko kantuk (Rendah/Sedang/Tinggi), dan saran.
- **Anggaran Screen Time**: total layar harian, proyeksi setelah pengurangan, dan waktu luang tambahan.
- **Rencana Jeda Malam**: checklist interaktif dengan indikator progres dan tombol reset.
- **Tujuan & Sasaran Pengguna**.

## Teknologi

HTML, CSS, dan JavaScript murni (tanpa framework dan tanpa instalasi).

## Struktur Folder

```
jedalayar/
├── index.html
├── style.css
├── script.js
├── README.md
└── img/
    ├── foto-doomscrolling.jpg
    ├── foto-kasur.jpg
    └── foto-kelas.jpg
```

Letakkan fotomu di folder `img/` dengan nama di atas. Jika belum ada, halaman menampilkan bingkai kosong.

## Cara Menjalankan

1. Unduh atau clone repositori ini.
2. Buka `index.html` di browser.

Di Codespaces, bisa juga dengan ekstensi **Live Server** atau perintah `python3 -m http.server 8000`, lalu buka port 8000.

## Cara Publikasi (GitHub Pages)

Settings → Pages → Branch `main` / folder `/ (root)` → Save.

## Catatan

Perhitungan bersifat estimasi edukatif untuk membantu kebiasaan tidur dan manajemen waktu layar pelajar. Bukan pengganti saran tenaga kesehatan.
